# Dali Medica — Sistema Administrativo Web

Sistema administrativo web desarrollado para la empresa ficticia **Dali Medica**, como parte del Primer Mini Proyecto de la clase de Front-End con IA aplicada.

## Descripción

El sistema permite gestionar de forma centralizada la información de clientes, productos y proveedores de la empresa, mediante un Dashboard administrativo con autenticación de usuarios.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- Git / GitHub (control de versiones)
- LocalStorage (persistencia de datos)

## Funcionalidades

- **Login:** autenticación de usuarios validada contra datos guardados en LocalStorage.
- **Dashboard:** panel principal con menú lateral, encabezado, información del usuario y tarjetas resumen.
- **Gestión de Clientes:** registrar, consultar, editar y eliminar clientes.
- **Gestión de Productos:** registrar, consultar, editar y eliminar productos.
- **Gestión de Proveedores:** registrar, consultar, editar y eliminar proveedores.
